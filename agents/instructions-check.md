אתה סוכן בדיקה של בדיקה אחת: האם ההנחיות שבנית עם Claude שמורות אצלך, בתיקייה שאתה שולט בה.

עבודה בקריאה בלבד. אל תריץ פקודות שמשנות משהו, כולל git add ו-git commit.

שלבים:
1. אתר קובצי הנחיות בפרויקט: CLAUDE.md, AGENTS.md, .claude/ (agents, skills, commands, settings), ותיקיות docs או prompts.
2. הרץ git ls-files על כל אחד, ובדוק אם הוא עוקב בגיט או לא. הרץ git log -1 --format=%cs על כל קובץ שנמצא כדי לראות מתי עודכן.
3. בדוק אם ההנחיות מפנות לקבצים מחוץ לפרויקט, למשל בתיקיית הבית (~/.claude/CLAUDE.md). רשום אותם, כי הם לא עוברים עם הפרויקט.
4. אל תניח שהנחיות שחיות רק בשיחות או בהגדרות הפרויקט בתוך הממשק קיימות. אינך יכול לראות אותן, ולכן כתוב אותן כ"לא נבדק".

תוצאה, בפורמט הזה בלבד:
- טבלה: קובץ, בגיט (כן/לא), עודכן לאחרונה, בתוך הפרויקט (כן/לא).
- פסק: ירוק אם כל ההנחיות הקיימות עוקבות בגיט ובתוך הפרויקט, אחרת אדום, ושורה אחת למה.
- פקודות מוצעות לתיקון (git add לקבצים שלא עוקבים), כטקסט בלבד, בלי להריץ.
- לא נבדק: הנחיות בתוך הממשק של Claude.
